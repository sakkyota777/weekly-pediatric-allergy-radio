週刊・小児アレルギーラジオ

専門分野の新着論文を、毎週自動で「聞けるラジオ」に変えて届ける仕組み
— 自動化で毎週の面倒を解決する実例 —

太田真樹 武蔵村山病院　小児科専門医・小児アレルギー専門医

こんな面倒がありました！

  • 自分の専門分野の新着論文が毎週たくさん出る（例: 1週間で99件ヒット）
  • 全部は読めない。読んでも頭に残りにくい
  • 確認する時間は昼休みの30分くらいしかない

→ だから「読む」をやめて、「聞く」に変えた。
しかも毎週、自分で何もしなくても届くようにした。

毎週、自動で届く4点セット

  • 対話ラジオ台本 — 2人の掛け合い
  • 音声 MP3 — 約8〜10分
  • 図解 PNG — 要点3つずつ
  • Notion ページ — その場で再生できる

一度設定すれば、毎週勝手に回る

毎週月曜 7:00 — AIエージェントが新しい作業セッションを起動し、最初から最後まで自律実行

⏰ 定期実行 → 📚 論文DB検索 → ✍️ 3本厳選・台本 → 🔊 音声合成 → 🖼️ 図解生成 → 📤 GitHub保存 → 📬 Notion配信

ポイント: 人間の作業はゼロ。設定変更も「設定ファイルを1つ編集して push」するだけ。
番組名・検索条件・話者の声 — 全部コード管理。

実際のラジオを聞いてみる

2人のAI音声が、選んだ論文を対話形式で解説します。

▼ 2026年8月24日号（3:50〜4:50 抜粋・1分）

自動化を安定させる工夫

  • 認証を2系統に分離 — 論文DB・Notion はクラウド連携、音声合成APIは環境変数。ネットワーク設定不要
  • 設定は1ファイルに集約 — 番組内容を変えても定期実行の設定は触らない（Gitで履歴管理）
  • 配信は raw URL 経由 — GitHub に push → Notion が音声・画像をページ内再生
  • 配信監視 — 月曜朝に未配信を検知して GitHub Issue を自動作成
